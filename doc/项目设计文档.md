# SemiRisk 项目设计文档

## 1. 项目定位

SemiRisk 是面向半导体产业链的 AI 风险智能平台，覆盖数据采集、风险识别、AI 推理、预警派发、GIS 监控、企业画像、RAG 知识检索和报告生成闭环。

## 2. 技术栈

- 后端：Java 21、Spring Boot 3.5、Spring MVC、Validation、Actuator、Maven 多模块
- 前端：Vue 3、Vite、原生 CSS、Fetch API
- 构建：Maven Wrapper
- 状态：演示环境使用内存状态；MySQL、Redis 等中间件配置默认指向 `192.168.101.128`
- 部署：后端使用 `script/start-backend-services.sh`，前端使用 `script/start-ui.sh`

## 4. 架构设计

系统当前采用前后端分离 + 微服务模块架构：

- `semirisk-ui`：Vue 前端，统一访问 Gateway API
- `semirisk-gateway`：认证、页面 API 聚合、兼容入口、CORS
- `semirisk-data-service`：爬虫、每日数据刷新、上传/ETL 扩展边界
- `semirisk-risk-service`：每 24 小时自动风险测算、风险评分 API
- `semirisk-ai-service`：AI API Key 管理、AI 报告分析占位、模型调用扩展
- `semirisk-alert-service`：告警查询和状态流转边界，优先面向 MySQL
- `semirisk-report-service`：报告异步任务边界，后续接 MQ 和文件渲染
- `semirisk-common-core`：公共响应结构、服务端口、角色权限策略
- `semirisk-common-db`：预编译 SQL 模板和数据库共享约束
- `semirisk-common-middleware`：虚拟机中间件默认地址与端口
- `semirisk-common-ai`：AI 默认模型、Endpoint、环境变量名

## 5. 中间件设计

所有中间件统一使用虚拟机 IP `192.168.101.128`：

- MySQL：业务数据持久化
- Redis：登录失败计数、Token、验证码、短期任务状态
- Elasticsearch：RAG Hybrid Search
- MinIO：上传文件、PDF、报告文件存储
- RabbitMQ：ETL、报告生成和 Agent 异步任务
- Nacos：后续微服务注册配置中心

当前版本为保证本机可立即运行，各服务保留内存兜底；Gateway 核心接口已采用数据库优先策略。Flyway 迁移脚本位于 `semirisk-services/semirisk-gateway/src/main/resources/db/migration`，连接 VM MySQL 后可通过 `SEMIRISK_FLYWAY_ENABLED=true` 自动迁移。

## 6. 关键业务流

### 6.1 登录与防爆破

用户提交账号、密码、验证码标识。后端在 5 分钟窗口内统计失败次数，达到 5 次锁定 30 分钟。登录成功后写入 Session 并返回前端 Token。
Redis 可用时失败计数和锁定状态写入 Redis；Redis 不可用时回退到内存计数。

### 6.2 数据上传清洗

前端支持点击、拖拽文件上传。后端限制 50MB，创建上传任务；用户点击解析后任务进入“导入成功”状态。SSE 接口实时推送 AI 清洗日志。

### 6.3 爬虫与每日刷新

`semirisk-data-service` 每天 00:00 拉取配置源网页，抽取标题和风险信号；当外部源不可达时使用本地风险基线兜底。`semirisk-risk-service` 每天 00:10 基于爬虫记录自动计算本日风险评分。`semirisk-ai-service` 每天 00:20 生成本日 AI 报告占位。

### 6.4 告警处理

预警中心从 `/api/alerts` 拉取告警，支持关键词、等级、状态组合筛选。忽略告警会调用后端更新状态，并在前端淡出行项。批量处理会批量流转为“处理中”。

### 6.5 报告生成

用户选择模板、语言、格式后创建异步报告任务。前端轮询任务进度，完成后下载报告文本文件。后续可替换为 PDF、Word、PPT 渲染服务。

### 6.6 系统管理

系统管理页支持用户新增、启停、模型 Ping、Agent 触发、数据源重连等交互，均绑定后端 API。
系统管理页提供 AI 模型 Endpoint 与 API Key 配置入口，默认模型为 `deepseekv4-pro`，默认 Endpoint 为 `https://api.deepseek.com/v1`，Key 通过 `SEMIRISK_AI_API_KEY` 或页面配置注入，并在后端脱敏保存。

### 6.7 前端工程拆分

Vue 前端使用 Vue Router + Pinia。视图组件位于 `src/views`，业务动作位于 `src/composables`，接口封装位于 `src/api`。路由守卫根据登录态和模块权限控制页面访问。

### 6.8 运行治理

Gateway 对每个请求写入 `X-Trace-Id`，日志格式包含 TraceId。接口文档通过 OpenAPI 暴露，默认地址为 `/swagger-ui.html`。

## 7. Git 分支规范

- `main`：稳定版本
- `develop`：集成分支
- `feature/maven-bootstrap`：Maven 与 Spring Boot 初始化
- `feature/static-pages`：目标页面复用与前端交互
- `feature/core-api`：业务 API 与内存状态服务
- `feature/docs`：文档、部署、数据库脚本

Commit 使用 `type(scope): subject`，例如 `feat(api): add alert workflow endpoints`。
