# SemiRisk 公网访问部署指南（frp 内网穿透）

## 网络架构

```
互联网用户
    ↓
云服务器 123.57.239.56（有公网 IP）
├── frps（frp 服务端，监听 7000）
├── frp 管理面板（7500）
└── 开放端口：8081, 8080, 8848, 9001, 9411, 15672（UFW + 阿里云安全组均需放行）
    ↓ (frp 隧道)
VM 192.168.101.130（内网）
├── frpc（frp 客户端，连接云服务器）
├── Docker Compose（7 中间件 + 1 应用）
│   ├── mysql:8.4
│   ├── redis-master:7.4 (6379) + redis-replica-{1,2,3}:7.4 (6380-6382)
│   ├── elasticsearch:8.15.3
│   ├── minio
│   ├── rabbitmq:3.13-management
│   ├── nacos:v2.4.3
│   ├── zipkin:3.4
│   └── semirisk-app:latest（6 个 Java JAR + Nginx）
```

## 完整部署流程

### 第一步：云服务器 123.57.239.56 安装 frp 服务端

```bash
# 1. 登录云服务器
ssh root@123.57.239.56

# 2. 将 frps 配置文件上传到云服务器
# 从本机执行：
scp script/install-frps.sh script/frps.toml root@123.57.239.56:/root/

# 3. 在云服务器上执行安装
chmod +x install-frps.sh
./install-frps.sh
```

安装完成后：
- frps 监听端口：`123.57.239.56:7000`
- 管理面板：`http://123.57.239.56:7500`（admin/admin）
- 日志：`/var/log/frps.log`

**云服务器防火墙需要开放的端口：**
| 端口 | 用途 |
|------|------|
| 7000 | frp 通信端口 |
| 7500 | frp 管理面板 |
| 8081 | 前端页面（映射） |
| 8080 | API Gateway（映射） |
| 8848 | Nacos 控制台（可选） |
| 9001 | MinIO 控制台（可选） |
| 9411 | Zipkin（可选） |
| 15672 | RabbitMQ 管理（可选） |

### 第二步：VM 192.168.101.130 安装 frp 客户端

```bash
# 1. 将 frp 客户端脚本同步到 VM
# 从本机执行：
rsync -avz --exclude='.git' --exclude='target/' \
  --exclude='node_modules/' --exclude='dist/' \
  script/install-frpc-on-vm.sh \
  kaduox@192.168.101.130:/opt/semirisk/script/

# 2. 登录 VM
ssh kaduox@192.168.101.130

# 3. 在 VM 上执行安装
cd /opt/semirisk
sudo bash script/install-frpc-on-vm.sh
```

安装完成后：
- frpc 连接云服务器：`123.57.239.56:7000`
- 端口映射：VM 80 → 云服务器 8081，VM 8080 → 云服务器 8080

### 第三步：部署 Docker 容器

```bash
# 在 VM 192.168.101.130 上执行
cd /opt/semirisk

# 1. 编译后端
./mvnw -q -DskipTests clean install

# 2. 构建前端
cd semirisk-ui && npm ci && npm run build && cd ..

# 3. 构建 Docker 单镜像
docker build -t semirisk/app:latest -f deploy/Dockerfile.single .

# 4. 启动全部服务
docker compose up -d

# 5. 等待就绪
sleep 90
docker compose ps
```

### 第四步：验证公网访问

```bash
# 从任意电脑浏览器访问
http://123.57.239.56:8081          # 前端页面
http://123.57.239.56:8080        # API Gateway
http://123.57.239.56:8080/swagger-ui.html  # API 文档
http://123.57.239.56:8848/nacos  # Nacos 控制台
http://123.57.239.56:9001        # MinIO 控制台
http://123.57.239.56:9411        # Zipkin
http://123.57.239.56:15672       # RabbitMQ 管理
```

## 常见问题

### Q1: frpc 连接不上 frps

```bash
# 在 VM 上测试 frp 服务端连通性
telnet 123.57.239.56 7000

# 检查 frpc 日志
journalctl -u frpc -n 30

# 检查云服务器 frps 是否运行
ssh root@123.57.239.56
systemctl status frps
```

### Q2: 云服务器防火墙阻止连接

```bash
# 在云服务器上检查端口
ss -tlnp | grep 7000

# 如果使用 cloud firewall（阿里云/腾讯云安全组）
# 需要在云控制台的安全组中开放：
# 入方向：TCP 7000, 8081, 8080, 7500
```

### Q3: frpc 频繁断线

```bash
# 查看 frpc 日志中的断线原因
journalctl -u frpc -n 50 | grep -i disconnect

# 检查网络稳定性
ping -c 10 123.57.239.56
```

### Q4: 前端能打开但 API 请求失败

```bash
# 检查 frpc 端口映射是否正常
curl -sf http://127.0.0.1:80
curl -sf http://127.0.0.1:8080

# 检查 Docker 容器是否正常
docker compose ps

# 检查 frpc 日志
journalctl -u frpc -n 50
```

## 安全建议

1. **修改默认密码**：frp 管理面板默认 admin/admin，务必修改
2. **修改 token**：frps.toml 和 frpc.toml 中的 token 应使用强随机字符串
3. **限制管理端口**：7500 端口只在内网访问，不要在公网暴露
4. **HTTPS**：生产环境建议在前端加一层 Nginx 做 HTTPS 反代
5. **定期更新**：保持 frp 和 Docker 镜像为最新版本
