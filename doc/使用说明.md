# SemiRisk 使用说明

## 1. 架构说明

当前版本为前后端分离 + Maven 多模块微服务结构：

- `semirisk-ui`：Vue 3 + Vite 前端，默认端口 `5173`
- `semirisk-gateway`：API 网关和兼容入口，默认端口 `8080`
- `semirisk-data-service`：爬虫与本日数据刷新服务，默认端口 `8081`
- `semirisk-risk-service`：AI 风险自动测算服务，默认端口 `8082`
- `semirisk-ai-service`：AI API Key 配置与报告分析预留服务，默认端口 `8083`
- `semirisk-common`：共享响应结构与公共代码

## 2. 环境要求

- Java 21 或更高
- Node.js 20 或更高
- npm
- Maven 使用仓库自带 `mvnw`

## 3. 启动后端

启动全部后端服务：

```bash
./script/start-backend-services.sh
```

也可以单独启动网关：

```bash
./mvnw -pl semirisk-services/semirisk-gateway spring-boot:run
```

如果单独启动某个依赖 `semirisk-common` 的服务，先安装公共模块：

```bash
./mvnw -DskipTests install
./mvnw -pl semirisk-services/semirisk-gateway spring-boot:run
```

## 4. 启动前端

```bash
./script/start-ui.sh
```

访问：

```text
http://localhost:5173
```

默认账号：

```text
admin / password
analyst / risk2026
ops / ops2026
```

角色权限由 `semirisk-common/src/main/java/com/semirisk/common/RolePermissionPolicy.java` 统一维护：

- `ADMIN`：全部模块
- `ANALYST`：看板、分析、详情、报告、告警、GIS、企业画像、知识库
- `OPERATOR`：看板、上传、告警、GIS、企业画像、知识库

## 5. 中间件脚本

虚拟机 `192.168.101.128` 还未连接时，不需要启动中间件也可以本地演示。后续连接 VM 后，在 VM 上运行：

```bash
./script/install-vm-middleware.sh
```

本机检查连通性：

```bash
./script/check-vm-middleware.sh
```

## 6. 每日自动刷新

- 数据服务每天 `00:00` 执行爬虫刷新本日记录
- 风险服务每天 `00:10` 基于爬虫数据自动测算风险
- AI 服务每天 `00:20` 生成本日 AI 分析报告占位
- 网关也保留每日刷新兜底逻辑，保证只启动网关时仍能演示

也可以在 Vue 首页点击“立即重新测算”手动刷新。

## 7. AI API Key 配置

进入 Vue 前端的“系统管理”页面，填写：

- 模型名称
- Endpoint
- API Key

点击“保存配置”后，后端会脱敏保存 API Key。当前版本预留真实大模型调用入口，后续可在 `semirisk-ai-service` 中替换为实际 OpenAI、Claude 或私有模型调用。

## 8. 验证命令

后端：

```bash
./mvnw test
```

前端：

```bash
cd semirisk-ui
npm install
npm run build
```
