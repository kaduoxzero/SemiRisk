# SemiRisk PRD 原型文档

## 1. 产品定位

SemiRisk 是供应链风险智能管理系统，面向制造、物流、采购、质量、风控和管理层用户，帮助企业对供应商、物流、财务信用、质量合规等风险进行采集、研判、预警、处置和报告沉淀。

## 2. 用户角色

| 角色 | 目标 | 核心权限 |
| --- | --- | --- |
| 风控管理员 | 配置风险数据源、维护知识库、查看全部风险 | 系统管理、知识库、全量事件 |
| 业务处置人员 | 查看并处理分派风险事件 | 风险详情、预警中心 |
| 供应链经理 | 查看企业画像和高风险链路 | 总览、分析、企业画像、GIS |
| 管理层 | 查看风险态势和 AI 报告 | 总览、AI 报告 |
| 系统管理员 | 用户、角色、菜单、配置维护 | 平台系统管理 |

## 3. 信息架构

```text
SemiRisk
├─ 首页风险总览
├─ 数据上传
├─ 风险分析
├─ 风险详情
├─ AI 报告生成

├─ GIS 风险地图
├─ 企业画像

```

## 5. 核心业务流程

### 5.1 风险发现到闭环

```text
数据导入/API 接入
  -> 生成风险事件
  -> 总览与预警中心展示
  -> 处置人员查看详情
  -> 填写处置建议并更新状态
  -> 关闭事件
  -> 形成报告和知识沉淀
```

### 5.2 AI 报告生成

```text
用户选择模板和日期范围
  -> 后端查询 risk_event 真实数据
  -> 调用 risk-ai-service
  -> 有密钥：外部模型生成
  -> 无密钥：本地规则生成
  -> 保存 risk_report
  -> 前端展示报告结果
```

## 6. 非功能需求

- 性能：常规列表接口响应时间小于 2 秒。
- 可用性：核心服务容器异常退出后自动重启。
- 安全：所有业务接口经网关和认证鉴权访问。
- 审计：重要新增、修改、删除和处置动作应进入操作日志。
- 可维护性：业务配置通过 Nacos 管理，不在代码中硬编码生产地址和密钥。
- 可观测性：服务暴露健康检查，容器日志落盘。

## 7. 验收标准

- 用户可登录并进入风险总览。
- 风险 KPI、趋势、列表接口可正常返回。
- 风险事件可新增、编辑、删除和处置。
- 企业画像可展示企业及关联风险。
- AI 报告可在无外部密钥时生成离线报告。
- Docker Compose 能启动完整演示环境。
