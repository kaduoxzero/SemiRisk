# SemiRisk 项目自审报告

## 1. 自审结论

当前项目可本地运行，前端 Vue、后端 Maven 多模块、公开源爬虫、Token 认证权限、报告导出、预警处理、GIS 多线路和知识库 ES 检索链路已经打通。风险类页面已从固定演示数据改为公开 RSS 采集数据驱动；公开源不可达时显示待采集或采集失败。

## 2. 前端审查

- 结构：`src/api`、`src/composables`、`src/views`、`src/layout` 已拆分，页面不再集中在单文件逻辑中。
- 登录权限：未登录仅开放首页，登录/注册入口保留在侧栏账户区，顶部只显示未登录提示；登录失败会展示后端错误提示。
- 注册：前端校验 QQ 邮箱，后端二次校验；启动管理员为 `kaduoxli / 123qwe123`，公开注册账号默认为 `OPERATOR`。
- Token：前端保存 Bearer Token 和 `expiresAt`，30 分钟滑动有效；刷新当前路由会恢复并重载当前页面数据，过期刷新会回首页重新登录。
- GIS：已改为后端 `points` + `routes` 数据驱动，并提供 3D 立体视图、自动旋转、手动拖拽和点位弹窗，避免固定一条或少量假线路。
- 预警中心：已补状态筛选、复选框批量处理、公开源链接、已忽略过滤；点击详情仅展示当前告警，并提供中英文对照。
- 知识库：页面只保留 AI 智能体问答面板，展示答案、检索链路、引用、模型状态和 token 使用量。
- 固定分页：Dashboard、风险详情、企业画像和系统日志已改为固定长度分页面板，减少长页面纵向堆叠。

## 3. 后端审查

- 认证：登录注册优先持久化 MySQL `system_user`，密码 PBKDF2 哈希；登录失败计数优先走 Redis，Redis 不可用时内存兜底。
- 权限：Gateway 拦截器已按 URI 映射模块并执行后端 RBAC 校验，避免只依赖前端菜单隐藏。
- 安全：受保护接口使用 `Authorization: Bearer <token>`；写接口启用无 Cookie 签名 CSRF Token；响应头已加 CSP、nosniff、frame deny、referrer-policy 和 permissions-policy。
- 爬虫：`semirisk-data-service` 使用公开 RSS/Atom 源并返回原文 URL、维度、评分、采集状态；服务启动和手动刷新会实时爬取，数据、风险和 AI 自动刷新周期已统一为每 12 小时。
- Gateway：聚合公开源数据到 Dashboard、Alert、GIS、Knowledge、Risk Analysis。
- 告警：公开源告警状态写入 Gateway 状态集，忽略和批处理后可正确反映到默认列表和计数器。
- 报告：`ReportFileFactory` 统一生成 PDF、DOCX、PPTX，Gateway 和 report-service 复用。
- 知识库：Gateway 会把公开源成功记录写入 Elasticsearch `semirisk_knowledge`，搜索和问答优先走 ES，ES 不可用时回退本地公开源记录。
- AI 问答：`/api/knowledge/ask` 已结合本地知识库、公开源、ES 检索和 DeepSeek Chat Completions；返回 `aiCalled`、`modelStatus` 和 `usage.totalTokens` 用于确认真实调用。
- 启动账号：`BootstrapAdminProvisioner` 会在 Gateway 启动时初始化 `kaduoxli` 管理员，VM/MySQL 不可达时使用内存兜底，MySQL 可达时同步落库。

## 4. API 审查

- API 映射文档已补充 `/api/auth/csrf`、Bearer Token、权限矩阵、`/api/knowledge/ask`、GIS `routes`、报告格式下载、告警状态规则。
- 数据库查询仍通过 `JdbcTemplate` 预编译参数执行。
- OpenAPI 入口保留：`/swagger-ui.html`、`/v3/api-docs`。

## 5. 文档审查

- `项目设计文档.md` 已更新 Token 认证、启动管理员、公开源数据、12 小时爬取、ES 检索、DeepSeek 真实调用、报告格式、知识库智能体、告警详情中英对照和告警状态。
- `PRD原型文档.md` 已更新 Token 30 分钟滑动有效、GIS 3D、多线路、AI 问答、报告导出、固定分页和告警交互验收。
- `API映射文档.md` 已更新新增接口和字段语义。
- `使用说明.md` 已更新公开源刷新、AI 问答和部署说明。

## 6. 中间件审查

- 中间件默认地址仍为 `192.168.101.130`。
- 本地可通过 SSH 隧道连接 VM 中间件，也可无中间件运行核心演示链路。
- MySQL、Redis、MinIO、Elasticsearch、RabbitMQ、Nacos 的部署脚本仍在 `script/` 和 `compose/` 下。
- Flyway 脚本保留在 Gateway 资源目录，生产建议开启 `SEMIRISK_FLYWAY_ENABLED=true`。`script/semirisk-schema.sql` 也已兼容旧库字段补齐。

## 7. 剩余风险

- 公开 RSS 源不是专用商业数据源，文章覆盖度和时效性取决于源站。
- 企业工商权威数据源尚未接入，企业画像不会伪造工商字段，只显示待接入。
- DeepSeek 调用依赖可用的 API Key 和外网连通性；失败时会回退本地 RAG 摘要并在 `modelStatus` 中说明。
- 公开源告警状态当前为 Gateway 内存状态，生产应迁移到 MySQL 表。
- GIS 坐标为公开源区域映射，不等同实时物流 GPS，需要接入真实 GIS/Webhook 后替换。
- Bearer Token 当前为 Gateway 内存 Token，生产建议迁移到 Redis 并支持多实例共享与统一下线。
