# SemiRisk 需求文档

## 1. 项目背景

供应链风险具有来源分散、变化快、处置链路长、报告沉淀弱等特点。SemiRisk 在 RuoYi-Cloud-Plus 基础上扩展供应链风险管理能力，将企业画像、风险事件、知识库、GIS、AI 报告和预警闭环整合到统一平台，支撑企业级交付和演示部署。

## 2. 建设目标

- 建立统一风险事件台账。
- 建立企业画像和供应链角色视图。
- 支持风险趋势、等级、类别和区域分析。
- 支持高风险事件预警与处置闭环。
- 支持基于真实业务数据生成 AI 风险报告。
- 支持 Docker Compose 快速部署到 Linux 中间件主机。
- 提供完整使用、PRD、API 和需求文档。

## 3. 范围说明

### 3.1 本期范围

- 用户登录、注册、忘记密码。
- 风险总览。
- 风险事件 CRUD 与处置。
- 企业画像 CRUD 与画像查看。
- 风险知识库维护与检索。
- 风险数据源维护。
- AI 报告生成与历史报告查看。
- GIS 风险节点查询。
- Docker Compose 部署和基础 SQL 初始化。

### 3.2 非本期范围

- 复杂工作流审批。
- 代码生成器在线生成。
- 多模型智能体编排。
- 外部数据源真实对接后的调度补偿。
- 移动端专项适配。

## 7. 部署需求

- 中间件部署在 Linux 主机 `192.168.101.128`。
- 推荐将项目部署到 `/opt/SemiRisk`。
- 使用 Docker Compose 管理 MySQL、Redis、Nacos、AI、Java 服务和 Nginx。
- 生产密钥通过环境变量注入，不提交仓库。
- Nacos 配置以 `prod` 命名空间发布。
- Linux 主机可使用 `script/deploy-semirisk.sh` 完成构建、初始化、配置发布和启动。

## 8. 安全需求

- 业务接口必须通过网关访问。
- Token 使用 `Authorization` 请求头传递。
- 内部服务启用 same-token 调用校验。
- 数据库、Redis、Nacos 密码应在生产环境替换默认值。
- 外部模型 API Key 使用环境变量 `DEEPSEEK_API_KEY`。
- 上传文件大小遵循后端配置限制。

## 9. 性能需求

- 首页 KPI 接口 2 秒内返回。
- 普通分页列表 2 秒内返回。
- AI 报告生成允许较长耗时，但前端需要展示生成状态。
- 数据库核心查询字段已建立索引：企业、等级、状态、时间、租户。

## 10. 可观测性需求

- Java 服务暴露 Actuator 健康检查。
- AI 服务提供 `/health`。
- 容器配置 `restart: unless-stopped`。
- 日志目录挂载到 `script/docker/logs` 或服务对应日志目录。
